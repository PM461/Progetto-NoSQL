This repository contains a project developed with a collegue @ Università degli Studi di Torino during my CS master's degree in Artificial Intelligence.

The project was made for the course "Modelli e Architetture Avanzati di Basi di Dati" and develops a NOSQL database based on Riak and MongoDB.
The main idea is to manage the e-commerce of a website that sells books, in which the library adapts to every Country (eg. Italy, France, Germany), so that every Country has its own books in their respective language.
We didn't develop the frontend for this project.
